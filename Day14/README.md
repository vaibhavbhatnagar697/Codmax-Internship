# Blog Website

A Full Stack Blog Website built during my internship at Codomax Digital
Solutions.

## Features

- Create Blog Posts
- View Blogs
- Edit Blogs
- Delete Blogs
- Responsive Design
- Express.js Backend APIs
- Fetch API Integration
- Modern UI with CSS Animations

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Git & GitHub

## Installation

1. Clone the repository

git clone <repository-link>

2. Install dependencies

npm install

3. Run server

node server.js

4. Open browser

http://localhost:3200
